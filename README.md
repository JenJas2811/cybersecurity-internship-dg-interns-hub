Cybersecurity Internship tasks and practical work covering networking fundamentals, network troubleshooting, IP addressing, subnetting, and Cisco Packet Tracer.

- TCP/IP Model
- Network Protocols
- IPv4 & IPv6 Addressing
- Public & Private IP Addresses

### Practical Work

- `ipconfig` – Basic IP configuration
- `ipconfig /all` – Detailed network configuration
- `tracert` – Network path and hop analysis
- Cisco Packet Tracer – PC–Switch–Router topology
